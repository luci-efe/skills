# Docs

One short page per skill. Install and overview live in the [root README](../README.md); the cross-skill rules in [CONTRACTS.md](CONTRACTS.md).

| Skill | What it does |
|---|---|
| [/doctor](doctor.md) | Check that the suite's tools are installed and wire the Claude hooks. |
| [/compass](compass.md) | Routes a task to the right skill and probes its prerequisites. |
| [/cartographer](cartographer.md) | Maps one domain or flow to verified symbols, invariants and tests. |
| [/crucible](crucible.md) | Pressure-tests an underspecified change: read the code first, ask only what it cannot answer. |
| [/council](council.md) | Several model families review one artifact in two rounds through Herdr panes. |
| [/reproduce](reproduce.md) | No fix without an observed failure; the deliverable is a regression test. |
| [/proof](proof.md) | Runs declared checks and records evidence before anyone says "done". |
| [/red-team](red-team.md) | Checks known-vulnerability exposure and separates affected, suspected, confirmed and unknown. |
| [/relay](relay.md) | Hands work to a fresh session or another agent as an immutable checkpoint plus durable decisions. |

Worked, real-output examples for every skill: [../examples/](../examples/README.md).

See also [memory.md](memory.md) for how checkpoints and mnemosyne fit together.
